# Andrey Silva — Data & Cloud Portfolio

Portfólio estático com HTML, CSS e JavaScript, preparado para publicação no GitHub Pages.

## Recursos
- Identidade visual Dark Tech (azul-marinho, ciano e laranja).
- Alternância de idioma Português / Inglês.
- Layout responsivo para desktop, tablet e celular.
- Filtros de projetos por Analytics, Engineering e Science.
- Navegação mobile, animações CSS e respeito à preferência `prefers-reduced-motion`.
- Sem dependências de build ou framework.

## Publicar no GitHub Pages
1. Extraia todos os arquivos deste ZIP.
2. No repositório que publica seu portfólio, substitua os arquivos antigos pelos arquivos desta pasta.
3. Faça commit e push para a branch configurada no GitHub Pages (normalmente `main`, pasta `/root`).
4. Em **Settings → Pages**, confirme a branch e a pasta de publicação.
5. Aguarde a publicação e teste o endereço.

## Personalizações importantes antes da publicação
- O endereço de e-mail e o perfil GitHub foram mantidos conforme as referências disponíveis.
- O link do repositório Olist foi mantido como `https://github.com/Andrey-Silva-Data/ecommerce-end-end`.
- O endereço exato do LinkedIn e links individuais dos outros projetos não estavam disponíveis na referência consultada; por isso, não foram inventados. Adicione-os quando confirmar os URLs.
- Os projetos indicados como “Em breve” continuam identificados como planejados, não como entregas concluídas.
- A formação/certificações AWS deve ser conferida para distinguir certificações efetivamente obtidas de cursos e trilhas de estudo.

- `index.html` — conteúdo e estrutura.

## Observações
Os elementos gráficos dos cards são ilustrações CSS abstratas, não gráficos com dados reais. Atualize os textos e links diretamente nos arquivos conforme os projetos evoluírem.
